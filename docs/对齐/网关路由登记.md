# 网关路由登记（report）

对齐挂号仓 `consult-gateway`：浏览器流量经网关验签与限流后转发本服务。

| 前缀 | 目标服务 | 说明 |
| --- | --- | --- |
| `/api/report/**` | `report-interpreter-service` | 患者端报告解读 API |
| `/internal/report/**` | `report-interpreter-service` | 内部令牌接口；网关或内网直连，浏览器不可达 |

本分支（foundation）先在文档登记；实际改挂号网关路由在联调里程碑提交挂号仓 PR。

本地直连开发端口见 `application.yml` 的 `server.port`（默认 `18092`）。
